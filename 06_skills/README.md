# 06_skills

这个示例演示了 **Skills（技能）系统**：把一类稳定、可复用的能力封装起来，让 Agent 按需加载并使用。

## 什么是 Skill

你可以把 Skill 理解为：

- 一份可复用的任务模板
- 一组专门的操作说明
- 一段与特定场景对应的能力包

例如：

- 写代码
- 生成文档
- 处理 PDF
- 做数据分析
- 完成某类固定工作流

## 为什么要有 Skills

如果没有 Skills，Agent 每次遇到类似任务都要重新“临场发挥”。

有了 Skills 之后，可以：

- 降低重复提示词编写成本
- 让能力模块化
- 让特定任务有稳定的执行方式
- 提高输出一致性

## 工作流程

```text
用户提出任务
   ↓
Agent 判断是否需要某个 skill
   ↓
加载 skill 内容
   ↓
按照 skill 约定执行任务
   ↓
输出结果
```

## 运行方式

```bash
uv run 06_skills/main.py
```

## 你可以关注的内容

- skill 是如何被发现和加载的
- skill 内容如何影响模型行为
- 如何把通用 Agent 变成“领域 Agent”

## 典型扩展方向

- 为不同场景建立 skill 目录
- 给 skill 增加版本管理
- 支持自动选择最匹配的 skill
- 将 skill 与 subagent 组合使用

如果你的项目经常重复处理相似任务，Skills 会非常有价值。
